DOC TITLE
Cloud Integration - Main Capabilities

1. PURPOSE
- Cloud Integration combines design-time content creation with runtime execution and monitoring.
- Its practical value comes from adapters, routing, transformation, and security working together.

2. SCOPE
- Primary source scope: Main Capabilities and closely related SAP Help pages.
- Chunking hint: design; connect; transform; secure.
- Preferred retrieval anchors: main capabilities, design, connect, transform, main.

3. KEY TERMS
- Design
- Connect
- Transform
- Secure
- Operate

4. CORE EXPLANATION
- Design and artifact management: create packages and integration flows, structure content, and maintain reusable assets.
- Connectivity: connect systems through protocol- and application-specific adapters.
- Transformation and mediation: reshape payloads, route messages, enrich headers and properties, and apply custom logic where needed.
- Operations: deploy content, monitor processing, and use trace or logs for diagnosis.
- Security handling usually includes stored credentials, certificates, trust material, and protocol-level authentication settings.
