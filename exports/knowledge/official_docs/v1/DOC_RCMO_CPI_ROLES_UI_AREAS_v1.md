Cloud Integration - Roles and UI Areas

1. PURPOSE
- Most users move across a small set of recurring work areas: design, monitor, and administration-oriented settings.
- Different personas touch different parts of the UI at different times.

2. SCOPE
- Primary source scope: Roles and UI Areas and closely related SAP Help pages.

4. CORE EXPLANATION
- Design | Monitor | Security | Help/About
- Design-oriented areas are used to create or maintain integration content.
- Monitoring-oriented areas are used to inspect deployments, message processing, and technical status.
- Administrative areas are used for credentials, certificates, and related runtime configuration.
- Help/about areas are useful when users need documentation or software version context.

5. OPERATIONAL RELEVANCE
