# Interface Catalog Reference Style

The interface catalog post-processing layer in `app/services/interface_catalog_formatter.py` enforces the following output contract:

- left-aligned markdown with no artificial indentation
- metadata kept as a flat key/value block below the title
- numbered sections in this order:
  1. PURPOSE
  2. SCOPE
  3. KEY TERMS
  4. CORE EXPLANATION
  5. OPERATIONAL RELEVANCE
  6. RELATED ARTIFACTS
- every line inside numbered sections rendered with `*` bullets
- no noisy generation lines such as:
  - `Generated by MCP knowledge orchestration ...`
  - `Generated at: ...`
- stable spacing between title, metadata, DOC ID, DOC TITLE, and numbered sections

This layer is intentionally formatting-only. It does not change the upstream content-selection logic; it normalizes the final markdown shape before files are written to disk.
