# Knowledge Generation v2.1.5

## Scope
This patch tightens markdown generation and update behavior for:
- KEDB
- Runbook
- Interface Catalog documentation

## Main changes
- Added strict style rendering for KEDB and Runbook outputs with left-aligned metadata and stable bullet formatting.
- Kept Interface Catalog output aligned with the approved reference style, including escaped underscores and `*` bullets.
- Removed artificial generator lines such as:
  - Generated by MCP knowledge orchestration ...
  - Generated at: ...
- Preserved existing document IDs during update flows when a prior version already defines them.
- Added local inventory fallback through `KNOWLEDGE_INVENTORY_PATH` to resolve package and iFlow metadata from exported inventory ZIP/JSON data when live SAP APIs are unavailable.
- Added optional OpenAI refinement through `OPENAI_API_KEY` for shorter, more action-led KEDB and Runbook bullets. Generation continues safely when the key is not configured or the API is unavailable.
- Improved local MPL ingestion by supporting additional JSON shapes such as `MessageErrors`, `MessageProcessingLogs`, and `items`.
- Added cleanup of noisy MPL error text patterns to reduce artificial stack-prefix noise in generated knowledge content.
- Added `resources/reference_materials/` with the provided formatting references, ingestion-policy guides, MPL samples, and inventory ZIP for controlled comparison and local testing.

## New environment options
- `KNOWLEDGE_INVENTORY_PATH`
- `OPENAI_API_KEY`
- `OPENAI_MODEL`
- `OPENAI_BASE_URL`

## Expected result
Newly generated and updated markdown files should now follow the same structural formatting family as the approved reference models while remaining compatible with the existing MCP tool flow.
